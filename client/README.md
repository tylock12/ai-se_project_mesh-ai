# MeshAI Client

React + TypeScript frontend for MeshAI, built with Vite.

## Features
- Register and log in
- Upload PDF documents to a knowledge base
- Chat with an AI assistant that answers from your documents

## Setup
1. Install dependencies: `npm install`
2. Start the dev server: `npm run dev`
3. The app runs at http://localhost:5173 and proxies `/api` requests to the server on port 3000.

## Scripts
- `npm run dev`: start the dev server
- `npm run build`: type-check and build for production
- `npm run lint`: run ESLint
